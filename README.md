# DiceChess

Регистрация и вход по нику и паролю на Ruby on Rails. Пароли хешируются через bcrypt.

Страницы: `/register`, `/login`, `/logout`. Лобби `/`, партии `/games/:id` и профили `/profile` (свой) и `/players/:id` открываются только после входа.

## Как сыграть партию

Нужны два аккаунта (например, в обычном окне и в окне инкогнито).

1. Первый игрок входит, в лобби выбирает цвет и контроль времени и нажимает «Создать партию».
2. Второй игрок входит, видит партию в «Открытых партиях» и нажимает «Играть».
3. Тот, чья очередь, нажимает «Бросить кубики», выбирает один из двух кубиков (значение определяет фигуру),
   нажимает на свою фигуру этого типа и на поле, подсвеченное точкой. Страница соперника обновляется сама.
4. Партия заканчивается матом, патом, сдачей, ничьей по согласию или вылетом по времени. Рейтинги меняются по итогам.

Ходить так, чтобы свой король остался под боем, нельзя. Если в шахе нет ни одного хода, это мат, если ходов нет без шаха, это пат.
Если ни одной фигурой по кубикам нельзя сходить (например, кубики не помогают выйти из шаха), появляется кнопка
«Ходов нет, бросить заново». Пешка, дошедшая до последней горизонтали, превращается в ферзя.

Создатель партии, пока соперника нет, может вернуться в лобби или отменить партию кнопкой «Отменить».

## Запуск

Нужны Ruby и PostgreSQL. По умолчанию подключение к `localhost`, пользователь `postgres` без пароля,
менять через `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD` (см. `config/database.yml`).

    bundle install
    ruby bin/rails db:create db:migrate
    ruby bin/rails server

Тесты: `ruby bin/rails test`

## База данных и модели

Схема базы (ER-диаграмма, таблицы, правила): [docs/database.md](docs/database.md).
Модели лежат в `app/models/`: `User`, `Game`, `GamePlayer`, `Move`, `DiceState`, `GameDiceState`, `TimeControl`,
`DrawOffer`, а также `Position` (позиция, которая восстанавливается из ходов) и `EloRating` (расчёт рейтинга).
Миграции применяются командой `ruby bin/rails db:migrate`, тесты моделей запускаются командой
`ruby bin/rails test test/models`.

## UI-кит

Стили лежат в `public/ui/`: `tokens.css` (цвета, отступы, шрифты, светлая и тёмная тема), `base.css`,
`components.css` (кнопки, формы, карточки, таблицы, меню), `icons.css`, `game.css` (доска, фигуры, кубики, часы,
список ходов, диалоги партии), `theme.js` (кнопка смены темы в шапке) и `clock.js` (ход часов в партии).
Все компоненты с примерами собраны на отдельной странице `public/ui-kit.html`: она открывается по адресу
`/ui-kit.html` и просто из папки проекта. Страница собирается из шаблона `app/views/ui/index.html.erb` командой
`ruby bin/rails ui:build` (после правок шаблона её нужно пересобрать). В development та же
страница доступна на лету по адресу `/ui`.
